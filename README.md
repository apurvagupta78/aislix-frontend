# Aislix Main

Build a modern SaaS web application called Aislix.

Aislix is an AI-powered Retail Shelf Intelligence platform that helps supermarkets, FMCG companies, distributors and Kirana stores automatically audit store shelves using computer vision.

The design should feel like Stripe, Notion, Linear and Vercel — premium, minimal, spacious and enterprise-grade.

Brand Color:

#0B8F4D

Primary Font:

Inter

Use rounded cards, soft shadows, lots of white space and smooth animations.

The application should contain these pages:

1. Landing Page

2. Login

3. Signup

4. Dashboard

5. Upload Scan

6. Processing Screen

7. Scan Results

8. Scan History

9. PDF Report Viewer

10. Subscription & Billing

11. User Profile

12. Settings

Dashboard widgets should include:

• Total Scans

• Products Detected

• Brands Detected

• Average AI Confidence

• Low Stock Alerts

• Recent Scans

• Shelf Health Score

• Inventory Trend

• Top Brands

Use dummy data only.

Do NOT build the backend yet.

Only create the frontend UI with navigation between all pages.
